# Athletes & Mental Health (AAMH) — Official Website

## Project Overview
Athletes & Mental Health (AAMH) is an organization founded by Dr. Lovie Tabron, Ed.D., dedicated to destigmatizing mental health conversations in athletic spaces. The organization provides evidence-informed mental performance education, workshops, keynote speaking, coaching development, and consulting services to athletes, coaches, parents, and organizations across the country. This repository contains the official website for AAMH, designed to serve as the organization's digital presence and primary point of contact for potential clients and partners.

## What I Built
The AAMH website is a multi-page static website built with vanilla HTML, CSS, and JavaScript. It includes the following pages:

- **Home (index.html)** — Landing page introducing the organization, founder, core pillars, and featured programs
- **About (about.html)** — A scrollable, image-rich biography page detailing Dr. Lovie Tabron's personal story, credentials, and mission
- **Programs (programs.html)** — A full catalog of all 8 programs and services offered by AAMH with booking links
- **Contact (contact.html)** — An inquiry form that collects client information and sends it directly to the organization's email using EmailJS

---

## Technologies Used
- **HTML5** — Page structure and content
- **CSS3** — Custom styling, responsive layout, animations, and design tokens
- **JavaScript (Vanilla)** — Scroll spy navigation, hamburger menu, active link highlighting, and form handling
- **EmailJS** — Third-party service used to handle contact form submissions and deliver inquiries directly to the client's email
- **Google Fonts** — Montserrat and Dancing Script typefaces
- **Flaticon** — Custom PNG icons used in the pillar and program sections

---

## Key Features
- Sticky navigation bar with scroll spy that highlights the active section as the user scrolls
- Smooth scroll behavior between page sections
- Mobile-responsive layout with a hamburger menu for smaller screens
- Hero section with a gradient image overlay
- EmailJS-powered inquiry form with validation, success, and error handling
- Consistent branding across all pages using CSS design tokens (lime green, black, white color system)
- Instagram and Gmail social links in the footer across all pages
